# Studio Hernández

Premium editorial website for Studio Hernández, an architecture practice in Wuppertal focused on building within existing structures.

## Technology

- TanStack Start and React 19
- TypeScript and Vite
- Custom responsive CSS
- Netlify Image CDN for optimized project photography

## Local development

```bash
npm install
npm run dev
```

The production site is configured for Netlify through `netlify.toml`.
